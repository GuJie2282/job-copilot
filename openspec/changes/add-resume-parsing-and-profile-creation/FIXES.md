### ✅ 问题 3：手动填写表单复杂度

**原问题**：
- Design 中提到"分步表单（5 个步骤）"
- Tasks 中没有明确每个步骤的字段
- 可能低估工作量

**修复方案**：
细化了 Phase 5.7.4 的子任务，明确了 5 个步骤的详细字段：

```markdown
- [ ] 5.7.4 创建 `ManualForm.vue`（手动填写表单）
  - [ ] 5.7.4.1 实现分步表单（5 个步骤）
    - 步骤 1：基础信息（姓名、手机、邮箱、所在地）
    - 步骤 2：教育背景（学校、学历、专业、毕业年份、GPA）
    - 步骤 3：工作经历（公司、职位、时间、职责、成就）
    - 步骤 4：技能与项目（技术技能、软技能、语言能力、项目经验）
    - 步骤 5：求职目标（目标岗位、目标公司、地点偏好、薪资范围、行业）
  - [ ] 5.7.4.2 添加步骤导航（上一步/下一步/跳过）
  - [ ] 5.7.4.3 实现表单验证（必填字段、格式检查）
  - [ ] 5.7.4.4 实现保存逻辑（调用 POST /api/resume/update-profile）
  - [ ] 5.7.4.5 添加"保存草稿"功能（允许稍后继续填写）
```

**影响**：
- ✅ 工作量评估更准确
- ✅ 开发者知道要实现什么
- ✅ 用户体验更好（分步降低心理负担）
- ✅ 新增"保存草稿"功能，提升 UX

**位置**：[tasks.md:198-205](tasks.md#L198-L205)

### ✅ 问题 4：演示场景不够详细

**原问题**：
- Phase 7 中只有"准备演示场景"
- 没有明确的演示脚本和讲解要点
- 可能导致演示时手忙脚乱

**修复方案**：
细化了 Phase 7.1.3 的演示脚本，包含 7 个详细步骤和讲解要点：

```markdown
- [ ] 7.1.3 准备演示脚本（操作流程、讲解要点）
  - **步骤 1**：打开"建立画像"页面（30 秒）
    - 讲解：这是求职 Copilot 的第一步，建立个人画像
  - **步骤 2**：展示上传前引导（30 秒）
    - 讲解：支持 PDF 和 docx，不支持扫描件，提供示例简历
  - **步骤 3**：上传示例简历（1 分钟）
    - 讲解：展示进度指示（上传→解析→提取→计算）
  - **步骤 4**：文本预览（30 秒）
    - 讲解：展示质量检测警告，用户可以修正文本
  - **步骤 5**：画像展示（1 分钟）
    - 讲解：展示结构化画像 + 置信度（绿/黄/红标签）
  - **步骤 6**：手动修正（30 秒）
    - 讲解：用户可以编辑任何字段，修正后置信度更新
  - **步骤 7**：完成后引导（30 秒）
    - 讲解：展示后续功能（JD 匹配、简历优化、模拟面试）
```

**影响**：
- ✅ 演示准备更充分
- ✅ 演示流程更清晰
- ✅ 演示时间可控（3 分钟）
- ✅ 讲解要点明确，不会遗漏亮点

**位置**：[tasks.md:300-318](tasks.md#L300-L318)
