## 🔧 技术实现

### 1. TypeScript 严格模式
所有代码使用 TypeScript 编写，配置严格模式：
- `strict: true`
- `noUnusedLocals: true`
- `noUnusedParameters: true`
- `noImplicitReturns: true`

### 2. 路由守卫
```typescript
// 未登录用户访问需要认证的页面 → 跳转到登录页
if (to.meta.requiresAuth && !isLoggedIn) {
  next({ name: 'Login', query: { redirect: to.fullPath } });
}

// 已登录用户访问访客页面 → 跳转到首页
if (to.meta.requiresGuest && isLoggedIn) {
  next({ name: 'Home' });
}
```

### 3. API 拦截器
- **请求拦截器**：自动添加 Authorization 头
- **响应拦截器**：统一错误处理、401 自动跳转登录

### 4. 状态管理
使用 Pinia 管理用户状态：
```typescript
const userStore = useUserStore();
await userStore.login(credentials); // 登录
await userStore.register(data);     // 注册
await userStore.logout();           // 退出
```

### 5. 响应式设计
- 桌面端（≥1024px）：完整布局
- 平板端（768px-1023px）：单列布局
- 移动端（<768px）：移动优化

## 🔗 与后端对接

### API 接口

#### 1. 登录接口
```typescript
POST /api/auth/login
Request: {
  email: string;
  password: string;
}
Response: {
  code: number;
  message: string;
  data: {
    user: User;
    token: string;
    refreshToken?: string;
  };
}
```

#### 2. 注册接口
```typescript
POST /api/auth/register
Request: {
  name: string;
  email: string;
  phone?: string;
  password: string;
  verificationCode: string;
}
Response: {
  code: number;
  message: string;
  data: {
    user: User;
    token: string;
    refreshToken?: string;
  };
}
```

#### 3. 发送验证码
```typescript
POST /api/auth/send-code
Request: {
  email: string;
}
Response: {
  code: number;
  message: string;
}
```

#### 4. 退出登录
```typescript
POST /api/auth/logout
Headers: {
  Authorization: Bearer {token}
}
Response: {
  code: number;
  message: string;
}
```

## 🆘 常见问题

### Q1: 启动失败？
A: 检查 Node.js 版本，确保 >= 16。删除 `node_modules` 后重新 `npm install`。

### Q2: API 请求 404？
A: 检查 `.env.development` 中的 `VITE_API_BASE_URL` 是否正确。

### Q3: 样式不生效？
A: 确保安装了 `sass` 依赖：`npm install -D sass`。

### Q4: TypeScript 报错？
A: 运行 `npm run build` 检查类型错误。
