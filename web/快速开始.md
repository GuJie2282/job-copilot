# 快速开始指南

## 🚀 完整系统启动（前端 + 后端）

### 第一步：启动后端服务（认证 API）

```bash
# 1. 进入后端目录
cd backend

# 2. 安装 Python 依赖
pip install -r requirements.txt

# 3. 初始化数据库（仅首次运行需要）
python -c "from src.models.base import Base, engine; Base.metadata.create_all(bind=engine); print('✓ 数据库初始化完成')"

# 4. 启动后端服务
python src/main.py
```

✅ **后端启动成功！**
- 后端地址：http://localhost:8000
- API 文档：http://localhost:8000/docs
- 健康检查：http://localhost:8000/health

📝 **后端验证码查看方式**：
在开发环境中，验证码会打印到后端控制台：
```
==================================================
📧 验证码发送到: zhangsan@example.com
🔢 验证码: 123456
⏰ 有效期: 5 分钟
==================================================
```

### 第二步：启动前端服务（Vue 3 界面）

```bash
# 打开新终端窗口

# 1. 进入前端目录
cd web

# 2. 安装依赖（仅首次运行需要）
npm install

# 3. 启动前端服务
npm run dev
```

✅ **前端启动成功！**
- 前端地址：http://localhost:3000
- 登录页面：http://localhost:3000/login
- 注册页面：http://localhost:3000/register

### 第三步：测试完整流程

1. 访问 http://localhost:3000/register
2. 填写注册信息，点击"获取验证码"
3. **查看后端控制台**，复制 6 位验证码
4. 完成注册
5. 登录并访问首页

## 技术亮点

### 1. TypeScript 严格模式
所有代码使用 TypeScript 编写，启用严格类型检查，确保代码质量。

### 2. 响应式设计
- **桌面端** ≥ 1024px - 完整布局
- **平板端** 768px - 1023px - 单列布局
- **移动端** < 768px - 移动优化

### 3. 状态管理
使用 Pinia 进行全局状态管理，包括：
- 用户登录状态
- 用户信息
- Token 管理

### 4. 路由守卫
- 未登录用户自动跳转到登录页
- 已登录用户访问登录页自动跳转到首页

### 5. API 拦截器
- 请求拦截：自动添加 Authorization 头
- 响应拦截：统一错误处理、Token 过期处理

## 常见问题

### Q: 安装依赖失败？
A: 请检查 Node.js 版本，建议使用 Node.js 16+。可以尝试删除 `node_modules` 和 `package-lock.json` 后重新安装。

### Q: 端口被占用？
A: 修改 `vite.config.ts` 中的 `server.port` 配置。

### Q: API 请求失败？
A: 按以下步骤检查：
   1. 后端服务是否启动（访问 http://localhost:8000/health）
   2. 前端 `.env.development` 配置是否正确（应该为 `http://localhost:8000`）
   3. 浏览器控制台是否有 CORS 错误
   4. 后端控制台是否有错误日志

### Q: 如何构建生产版本？
A: 运行 `npm run build`，构建产物在 `dist` 目录。
